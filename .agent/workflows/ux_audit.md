## 🔍 THE JOURNEY PATH
1. **Journey Mapping**: Define the start state, target state, and expected clicks for a specific user goal (e.g., "Registration to First Sale").
2. **Heuristic Audit**: Evaluate the UI against the 10 core UX heuristics (Visibility, Real-world Match, Control, Consistency, Error Prevention, Memory, Flexibility, Aesthetics, Recovery, Help).
3. **Friction Scrying**: Use the browser subagent (`/reveal`) to traverse the journey. Record any DOM layout shifts, confusing contrast ratios, missing hover states, or dead clicks.
4. **Actionable Recommendations**: Output a concrete, code-actionable plan (e.g., "Increase hit target to 48px", "Add Framer Motion layoutId for state transition").
